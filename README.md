## Arquitectura del proyecto

El proyecto implementa un pipeline modular de Inteligencia Artificial en Python que sigue el principio de separación de responsabilidades: cada etapa del flujo (carga de datos/data_loader, preprocesamiento/preprocessing, modelado supervisado/supervised_model y no supervisado/unsupervised_model) está encapsulada en su propio módulo independiente, y un archivo orquestador (main.py) coordina la ejecución secuencial de todo el pipeline.
